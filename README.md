## Работа с программой
### Главное меню
При запуске программы отображается главное меню:

```text
=== База данных ===
1. Создать таблицу
2. Все таблицы
3. Работа с таблицей
0. Выход
Создание таблицы
```
При выборе пункта "1" запускается процесс создания новой таблицы:

```text
Имя таблицы: students
Колонки (пустая строка - конец):
1: id
2: name
3: age
Таблица students создана
```
### Работа с таблицей
При выборе существующей таблицы открывается меню работы с ней:

```text
--- Таблица students ---
1. Все записи
2. Добавить
3. Найти
4. Обновить
5. Удалить
0. Назад
```

### Добавление записи
```text
name: Иван Петров
age: 20
Добавлено
```

### Поиск по фильтру
```text
age (Enter=пропустить): 20
1. ['Иван Петров', '20']
```

### Обновление записей

```text
Фильтр для обновления:
name: Иван
Новые данные:
age: 21
Обновлено
```

### Удаление записей
```text
Фильтр для удаления:
age: 21
Удалено
```
